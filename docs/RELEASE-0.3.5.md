# Maguro 0.3.5 release notes

A small fix release on top of 0.3.4.

## Fixes

- **Alt+Z opens one tab.** With a folder path on the clipboard, one Alt+Z press opens exactly one tab. Holding the keys a little longer no longer opens the same folder twice. Win+Shift+E gets the same guard.
- **Keyboard focus after a tab switch.** Switching tabs with Shift held (Ctrl+Shift+Tab) keeps keyboard focus on the items. The selection stays blue, and Down moves to the next row instead of opening the Name column filter.

## Documentation

- **README and help.** The preview pane, pane header and toolbar editor are described as they work now.
- **Screenshots.** New vertical and horizontal toolbar shots, cropped to the toolbar, and a close-up of the important mark, in English, Korean and Japanese.
